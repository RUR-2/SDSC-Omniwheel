┌─────────────────────────────────────────────────────────────────────────┐
│ 🎮 CONTROLS                                                              │
└─────────────────────────────────────────────────────────────────────────┘

  Left Stick (Analog 0/1):
    ↑ Forward     │ Push up → robot moves forward
    ↓ Backward    │ Pull down → robot moves backward
    ← Left        │ Push left → robot strafes left
    → Right       │ Push right → robot strafes right

  B6 / B7 (Digital):
    B6  → Rotate LEFT (counter-clockwise)
    B7  → Rotate RIGHT (clockwise)

  B4 (DEADMAN SWITCH) ⚠️:
    HOLD B4 to enable motion
    RELEASE B4 → robot STOPS immediately

┌─────────────────────────────────────────────────────────────────────────┐
│ 🚀 STARTUP PROCEDURE                                                     │
└─────────────────────────────────────────────────────────────────────────┘

  1. Setup Bluetooth:
     $ sudo rfcomm bind /dev/rfcomm0 <MAC_ADDRESS_ESP32> 1
     Example: sudo rfcomm bind /dev/rfcomm0 AA:BB:CC:DD:EE:FF 1

  2. Connect Joystick:
     - Plug in USB joystick
     - Turn on wireless controller
     - Check: ls /dev/input/js*

  3. Launch Controller:
     $ python3 bluetooth_sdsc.py

  4. In GUI:
     - Click "Refresh" to find /dev/rfcomm0
     - Click "Connect"
     - Status should show: "Connected [135° CW rotation active]"

  5. Verify Joystick:
     - Status should show: "Controller connected: <name>"
     - Move sticks → values should update

  6. READY TO GO!
     - HOLD B4 + move stick → robot moves
     - Release B4 → robot stops

┌─────────────────────────────────────────────────────────────────────────┐
│ 🛡️ SAFETY ZONES (bluetooth_sdsc.py only)                                │
└─────────────────────────────────────────────────────────────────────────┘

  🔴 INTIMATE  (< 0.45m)  → EMERGENCY STOP (0% speed)
  🟠 PERSONAL  (< 1.20m)  → SLOW DOWN (30% speed)
  🟡 SOCIAL    (< 3.60m)  → AVOIDANCE (70% speed)
  🟢 PUBLIC    (> 3.60m)  → NORMAL (100% speed)

  Robot automatically:
    - Detects humans with RealSense + YOLOv11
    - Calculates repulsive forces
    - Modulates velocity based on proximity
    - Emergency stops if too close

┌─────────────────────────────────────────────────────────────────────────┐
│ ⚠️ EMERGENCY PROCEDURES                                                  │
└─────────────────────────────────────────────────────────────────────────┘

  IMMEDIATE STOP:
    1. Release B4 (deadman switch)
    2. Or close the control window
    3. Or disconnect Bluetooth

  CONNECTION LOST:
    - Robot receives <127,127,127> (STOP)
    - GUI shows: "Bluetooth: Lost connection!"
    - Reconnect via GUI

  JOYSTICK UNPLUGGED:
    - Auto-sends STOP command
    - GUI shows: "Controller disconnected"
    - Replug and continue

  WINDOW LOSES FOCUS:
    - Auto-sends STOP command (safety feature)
    - Click window to regain control

┌─────────────────────────────────────────────────────────────────────────┐
│ 🔧 TROUBLESHOOTING                                                       │
└─────────────────────────────────────────────────────────────────────────┘

  Problem: Robot moves wrong direction
  └─ Solution: Check you're using bluetooth_sdsc.py or bluetoothconf.py
              (NOT bluetooth.py!)

  Problem: No /dev/rfcomm0 found
  └─ Solution: $ sudo rfcomm bind /dev/rfcomm0 <MAC> 1
              $ ls -la /dev/rfcomm*

  Problem: "Permission denied" on /dev/rfcomm0
  └─ Solution: $ sudo chmod 666 /dev/rfcomm0
              Or add user to dialout group:
              $ sudo usermod -aG dialout $USER
              (logout/login required)

  Problem: Joystick not detected
  └─ Solution: $ ls /dev/input/js*
              $ jstest /dev/input/js0
              Try replugging USB

  Problem: Detection window not showing (bluetooth_sdsc.py)
  └─ Solution: Check RealSense camera:
              $ rs-enumerate-devices
              $ realsense-viewer

  Problem: High CPU usage (bluetooth_sdsc.py)
  └─ Solution: Normal - YOLO inference is heavy
              To reduce: lower DETECTION_RATE_HZ in code

  Problem: "Module not found" error
  └─ Solution: $ pip install -r requirements_sdsc.txt

┌─────────────────────────────────────────────────────────────────────────┐
│ 📞 QUICK COMMANDS                                                        │
└─────────────────────────────────────────────────────────────────────────┘

  Bind Bluetooth:
    $ sudo rfcomm bind /dev/rfcomm0 AA:BB:CC:DD:EE:FF 1

  Check Bluetooth:
    $ rfcomm -a

  Release Bluetooth:
    $ sudo rfcomm release /dev/rfcomm0

  Test Joystick:
    $ jstest /dev/input/js0

  Check Camera (for bluetooth_sdsc.py):
    $ rs-enumerate-devices
    $ realsense-viewer

  Kill Process (if stuck):
    $ pkill -f bluetooth_sdsc
    $ pkill -f bluetoothconf
