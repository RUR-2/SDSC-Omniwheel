═══════════════════════════════════════════════════════════════════════
⚠️ TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════

Issue: Robot still entering INTIMATE zone
────────────────────────────────────────
Quick Fix:
  1. Open bluetooth_sdsc.py
  2. Increase multipliers:
     LATERAL_MULTIPLIER_SOCIAL = 4.0  # was 3.0
     LATERAL_MULTIPLIER_PERSONAL = 7.0  # was 5.0
  3. Restart python script

Issue: Robot too aggressive / uncomfortable
────────────────────────────────────────
Quick Fix:
  1. Open bluetooth_sdsc.py
  2. Reduce multipliers:
     LATERAL_MULTIPLIER_SOCIAL = 2.5  # was 3.0
  3. Or increase speed:
     SPEED_MULTIPLIER_SOCIAL = 0.7  # was 0.6

Issue: Detection not working
────────────────────────────────────────
Check:
  1. RealSense camera connected? (rs-enumerate-devices)
  2. YOLO model present? (ls yolo11n.pt)
  3. Visualization window shows detections?

Issue: Bluetooth disconnects
────────────────────────────────────────
Check:
  1. rfcomm still connected? (rfcomm)
  2. ESP32 powered on?
  3. Try reconnecting in GUI
